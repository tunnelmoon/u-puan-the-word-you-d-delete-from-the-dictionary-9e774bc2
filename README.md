# The Word You'd Delete From the Dictionary

Entry for the make.fun bounty [The Word You'd Delete From the Dictionary](https://make.fun/bounty/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2).

`main.ts` writes one word to `/output/entry.txt`: **colonel**.

The word is spelled nothing like it sounds. Erase it and the dictionary loses its most famous liar, a word pronounced "kernel" that never once looked the part.
